# Demo script

Aim for about 1 minute 45 seconds. Record the desktop width, with the browser zoomed so the Noticed column and the pantry are both readable. Start from a fresh board: click **Reset the demo evening** if you have clicked around.

## 0:00–0:12 — The house already knows

Say: "This is Hearth, for the Yukhimets household. It noticed tonight on its own."

Show the Tonight card: spinach expires tomorrow, Mira's pickup and Mark's review fill the evening, and garlic is the only thing missing. Point at milk and oats marked **Low staple**. Do not click yet.

## 0:12–0:32 — Fridge to table

Say: "A fridge photo is optional. Without a key, Hearth still plans."

Click **Load sample shelf**. The dinner card should change: the sample read includes garlic, so the meal no longer needs a purchase. Say: "Grok vision does this from a real photo when a key is set. The planner only lists what is still missing."

If you have a key, open **Bring a key**, paste it, save, and upload a JPEG instead of the sample. Say the model name on the badge.

## 0:32–0:55 — One tap

Say: "Nothing is ordered. Approval writes the board."

Click **Approve** on "Cook the spinach tonight." The receipt says no order was placed. Show the shopping list: it is empty for the meal, or it holds only garlic if you skipped the sample. Click **Approve** on the milk and oats card. The schedule gains a grocery run tomorrow morning, not on top of tonight's review.

## 0:55–1:15 — Ask the agent

Say: "The same tools run as a published agent network, in the browser."

Click **What is running low?** If a consent card appears for the pantry network, click **Allow** and point out that the key is not sent. The answer names milk and oats. Open the trace under the chat and show either `MCP /mcp` or the in-browser fallback.

## 1:15–1:35 — It fails closed

Scroll to **House status**. Say: "Invalid networks, cycles, over-budget calls, and denied origins stop. A write that cannot be verified is not retried."

Read the Guards line. If you want the failure visible, clear the key and click **Check again**: Vision shows the fallback, and the planner row stays ok.

## 1:35–1:45 — Close

Say: "The manifest, the network JSON, and the MCP server are public. Hearth plans the house. A person still approves."

Leave `/agent-manifest.json` visible in a second tab for a beat, then cut.
